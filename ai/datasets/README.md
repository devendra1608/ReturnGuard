
# ReturnGuard Datasets

## Synthetic Returns

Generated by `generate_synthetic_returns.py`.

Generate 500 cases:

```powershell
.\services\api\.venv\Scripts\python.exe ai\datasets\generate_synthetic_returns.py --rows 500 --seed 42
```

Output:
`data/processed/synthetic_returns.csv`

## Important limitations

- All generated customer, order, and risk information is fictional.
- `risk_label` is a synthetic scenario label, not verified fraud.
- `expected_outcome` is an expected workflow outcome under the
  demonstration policy, not a financial authorization.
- The generator intentionally covers seven scenario types.
- Dataset quality and model performance must be evaluated
  before any claims about fraud detection are made.
